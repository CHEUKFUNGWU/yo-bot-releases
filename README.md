# Yo Bot downloads

Installers for [Yo Bot](https://getyobot.app), a desktop app: Bots with names that work on your own computer.

Get the latest build from the [Releases](../../releases/latest) page, or from [getyobot.app](https://getyobot.app).

- **macOS** (Apple silicon, macOS 13 or later): `Yo-Bot-mac-arm64.dmg`
- **Windows** (x64, preview): `Yo-Bot-windows-x64.exe`

The builds are not signed yet. On a Mac, the first launch is refused: open System Settings › Privacy & Security and press **Open Anyway**. On Windows, SmartScreen warns: choose **More info**, then **Run anyway**.

Questions: support@getyobot.app
